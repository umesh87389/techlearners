1. Introduction to ICT

What is ICT?

ICT stands for Information and Communication Technology.

It refers to all technologies used to create, store, process, share, and communicate information.

In simple words, whenever we use a computer, smartphone, internet, email, or video call to exchange information, we are using ICT.

Three Core Components of ICT

  • Information: Facts and figures that are of value to the recipient.
  • Communication: The act of receiving, giving, or sharing information with others in an understandable form.
  • Technology: The application of scientific knowledge to perform practical tasks in our daily lives.

Role of ICT

Information Technology (IT) aims at making required information available at a faster speed and with more ease.

Examples of ICT Tools

  • Desktops and Laptops
  • Smartphones
  • Tablets (Tab)
  • E-Readers (e.g., Kindle)
  • Radio and Television (TV)
  • Smart TV (ATV)
  • Internet and Email
  • Video conferencing

2. Importance of ICT

5 Key Developments in Daily Life

  3. Digital Payments: Payment of bills, taxes, school fees, and dues can be easily done using ICT applications.
  4. Advance Bookings: Railway, air, bus, and movie tickets can be booked in advance sitting at home.
  5. On-Demand Transport: You can call a taxi or cab using your mobile phone.

3. Components of ICT & ICT Tools

All those devices and equipment that are used for introducing information and communication technology in the work environment for enhancing the ease of operations and increasing the efficiency of work are called ICT tools.

ICT mainly consists of four parts:

A. Hardware

Physical parts of a computer that can be touched.

Hardware Tools: Desktops, laptops, smartphones, tablets, e-readers (Kindle), radio, TV, and Smart TV (ATV).

B. Software as an ICT Tool

Software is a series of instructions that make an ICT device work for us.

Popular Software Packages as ICT Tools

  • Electronic Spreadsheets: Used for classifying data and presenting it in table form. Provides formulas, automatic calculations, charts, and graphs (e.g., Microsoft Excel, Apple Numbers, Quip, EtherCalc).
  • Database Management Systems (DBMS): Used for storing large volumes of data on computers and retrieving it efficiently (e.g., MS-Access, MySQL, Oracle).
  • Web Browsers: Software using which the entire World Wide Web (WWW) can be searched and web pages viewed (e.g., Google Chrome, Microsoft Edge, Mozilla Firefox, Apple Safari).
  • Search Engines: Services used for finding any type of information on any topic on the internet using search terms (e.g., Google, Microsoft Bing, Yahoo, Baidu, DuckDuckGo).

General Types of Software

System software: Controls the computer system. Examples include Windows, Linux, and Android.

Application software: Used to perform specific tasks. Examples include word processors, spreadsheets, and presentation software.

C. Data

Data means raw facts and figures, such as student marks, names, mobile numbers, and attendance records.

When data is processed and becomes meaningful, it is called information.

Example: Data: 85, 90, 88. Information: Average score = 87.6.

D. Communication Technology

Technologies used to transfer information from one place to another.

Examples: Internet, Wi-Fi, Bluetooth, and mobile networks.

4. Computer System & Organisation

A computer system is an electronic machine that accepts data from us, processes it, stores it, and displays meaningful information.

Data vs. Information

  • Data: Raw facts and figures are termed as data.
  • Information: The result obtained after processing the data is called information.

Meaning of Processing

The act of performing arithmetic and logical operations is called processing.

  • Arithmetic Operations: Operations like addition (+), subtraction (-), multiplication (*), and division (/) are examples of processing.
  • Logical Operations: Relational comparisons like A > B, A = 100, and AGE < 65 are also examples of processing.

Working of a Computer (The IPO Cycle)

The computer performs all operations through the Input-Process-Output (IPO) Cycle:

Input Unit (Takes Data) → Processor (Processes Data) → Output Unit (Displays Result) → Information

Computer Organisation & Functional Units

The computer is an electronic data processing system comprising four major functional units:

  • Input Unit: Used for entering data. A keyboard is the main input unit used for entering data. Other input units include mouse, scanner, microphone, and webcam.
  • Central Processing Unit (CPU): The main unit (brain) of the computer used for data processing. Consists of three essential subunits:
    • Memory Unit (MU): Holds data, instructions, and intermediate results during processing.
    • Control Unit (CU): Directs operations and coordinates communication across all hardware units.
    • Arithmetic & Logic Unit (ALU): Performs all arithmetic calculations (+, -, *, /) and logical decisions.
  • Output Unit: Used for displaying the result. A monitor is the main output unit used on every computer. Other output units include printers, speakers, and projectors.
  • Storage Unit: Used to store data, programs, and files permanently for future use (Hard disks, SSDs, pen drives, memory cards).

5. Characteristics of a Computer

  • Speed: Performs millions of calculations quickly.
  • Accuracy: Produces correct results if instructions are correct.
  • Storage capacity: Stores large amounts of data.
  • Diligence: Does not get tired.
  • Reliability: Works consistently.
  • Versatility: Performs different types of tasks.

6. Input Devices

Input devices are used to enter data into a computer.

  • Keyboard: Used for typing text and numbers.
  • Mouse: Used for pointing, clicking, and selecting.
  • Scanner: Converts paper documents into digital form.
  • Microphone: Used to input sound.
  • Webcam: Used to capture images and videos.
  • Touchscreen: Allows users to interact by touching the screen.

7. Output Devices

Output devices are used to display processed information.

  • Monitor: Displays text, images, and videos.
  • Printer: Produces hard copies. Common types include inkjet and laser printers.
  • Speakers: Produce sound output.
  • Projector: Displays content on a large screen.

8. Storage Devices

Storage devices store data and information.

Primary Storage

Temporary storage used while working. Examples include RAM and cache memory.

  • Fast
  • Temporary
  • Data is lost when the power is off

Secondary Storage

Permanent storage. Examples include hard disks, SSDs, pen drives, memory cards, and DVDs.

  • Permanent
  • Large storage capacity

10. Operating System

An operating system (OS) is software that manages computer resources and acts as a bridge between the user and computer.

Functions

  • Manages files
  • Controls hardware
  • Runs applications
  • Provides a user interface

Examples: Windows, Linux, Android, and macOS.

11. Internet

The internet is a worldwide network connecting millions of computers.

Uses

  • Communication
  • Education
  • Banking
  • Shopping
  • Entertainment
  • Research

12. Web Browser

A web browser is software used to access websites.

Examples: Google Chrome, Mozilla Firefox, Microsoft Edge, and Opera.

13. Search Engine

A search engine is a service that helps find information on the internet.

Examples: Google, Bing, and Yahoo.

Search Tips

  • Use specific keywords.
  • Avoid unnecessary words.
  • Use quotation marks for exact phrases.

14. Email

Email stands for electronic mail. It is a method of sending and receiving messages through the internet.

Parts of an Email

  • To: Recipient's address.
  • Subject: Topic of the email.
  • Body: Main message.
  • Attachment: Additional files.

15. Advantages of Email

  • Fast communication
  • Low cost
  • Worldwide access
  • File sharing
  • Paperless communication

16. Digital Communication Tools

  • Email: Sending messages.
  • Chat applications: Instant communication.
  • Video conferencing: Face-to-face online meetings.
  • Social media: Sharing information globally.

17. Cyber Safety

Cyber safety means protecting devices, information, and users while using digital technologies.

Common Online Threats

  • Virus: Malicious software that damages files.
  • Malware: Software designed to harm systems.
  • Phishing: Fake messages intended to steal information.
  • Hacking: Unauthorized access to a system.

18. Safe Internet Practices

  • Use strong passwords.
  • Do not share OTPs.
  • Avoid suspicious links.
  • Install antivirus software.
  • Log out from public computers.
  • Update software regularly.

19. Strong Password Guidelines

A good password should contain uppercase letters, lowercase letters, numbers, and special characters.

Examples

Importance

Digital footprints can affect future opportunities and reputation.

Examples

  • Digital identity services
  • Online grievance systems

Supplementary: Personal Hygiene & Self-Confidence (Unit 2 Key Points)

Personal Hygiene

Personal hygiene is a habit or a practice through which we keep ourselves clean and maintain good health.

6 Golden Suggestions for Boosting Self-Confidence

  1. Take care of your body and maintain good health.
  2. Dress appropriately, neatly, and smartly.
  3. Maintain a positive circle of good friends.
  4. Talk to yourself positively each day.
  5. Respect others and be ready to help them.
  6. Learn to say "no" politely to unreasonable requests.

  • Storage devices: RAM, hard disk, SSD, and pen drive
  • Internet services: Email, browsing, online learning, and video calls
  • Cyber safety: Strong passwords, antivirus, and safe browsing
  • Digital footprint: A record of online activities
