1. Python Keywords: False, True, None, and, as, assert, break, class, continue, def, del, elif, else, except, finally, for, from, global, if, import, in, is, lambda, nonlocal, not, or, pass, raise, return, try, while, with, yield.
2. Mutable Types (can be changed in place): Lists, Dictionaries, Sets.
3. Immutable Types (cannot be changed in place): Integers, Floats, Booleans, Strings, Tuples.
4. Core Syntax Rules:
- Dynamic typing allows variable type to change during execution.
- Indentation (typically 4 spaces) defines block structures instead of curly braces.
- Comments start with #.
