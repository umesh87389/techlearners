# Tech Learners - AI Education Platform

A modern, glassmorphism-styled educational platform for Class 9 and Class 10 AI curriculum. Features include notes, video lectures, fuzzy search, dark/light mode, live class integration, and feedback system.

## Features

- 📚 Class-wise notes (Class 9 & 10 AI)
- 🎥 YouTube video lectures integration
- 🔍 Fuzzy search for notes and videos
- 🌓 System/Light/Dark theme support
- 📝 User feedback collection (stored in localStorage)
- 🔗 Google Meet live class links
- 💎 Glassmorphism UI with animated background orbs

## Tech Stack

- React 18 (CDN)
- Babel Standalone (for JSX)
- Fuse.js (fuzzy search)
- Font Awesome 6
- HTML5/CSS3 (Glassmorphism design)
