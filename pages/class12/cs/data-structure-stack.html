1. Introduction to Stack

A stack is an ordered collection of elements where insertion and deletion take place at the same end, called the top. The stack is a linear data structure that follows the LIFO (Last In, First Out) principle.

Analogy: A stack of plates in a cafeteria. The last plate placed on top is the first one removed. You cannot remove a plate from the middle without first removing the plates above it.

Characteristics:

  • Elements are added and removed only from the top.
  • The last element inserted is the first one to be removed.
  • Stack has a dynamic size (can grow or shrink).
  • Only the top element is accessible at any given time.

2. LIFO Principle

LIFO stands for Last In, First Out. The most recently added element is the one that is removed first.

# Pop:     [10, 20]  (removed 30)
# Pop:     [10]      (removed 20)

4. Stack Implementation using List

In Python, a list can be used to implement a stack efficiently. The end of the list serves as the top of the stack.

class Stack:
    def __init__(self):
        self.items = []

    def push(self, item):
        self.items.append(item)

    def pop(self):
        if not self.is_empty():
            return self.items.pop()
        return None

    def peek(self):
        if not self.is_empty():
            return self.items[-1]
        return None

    def is_empty(self):
        return len(self.items) == 0

    def size(self):
        return len(self.items)

    def display(self):
        print("Stack (top to bottom):", self.items[::-1])

5. Push Operation

The push operation adds an element to the top of the stack.

def push(self, item):
    self.items.append(item)
    print(f"Pushed {item} to stack.")

Algorithm:

  1. Accept the element to be inserted.
  2. Append the element to the end of the list.
  3. Increment the size of the stack.

6. Pop Operation

The pop operation removes and returns the top element from the stack.

def pop(self):
    if self.is_empty():
        print("Stack is empty. Cannot pop.")
        return None
    item = self.items.pop()
    print(f"Popped {item} from stack.")
    return item

Algorithm:

  1. Check if the stack is empty. If empty, return underflow error.
  2. Remove and return the last element from the list.
  3. Decrement the size of the stack.

7. Peek/Top Operation

The peek operation returns the top element without removing it.

def peek(self):
    if self.is_empty():
        print("Stack is empty.")
        return None
    return self.items[-1]

8. isEmpty Operation

The isEmpty operation checks whether the stack has any elements.

def is_empty(self):
    return len(self.items) == 0

9. Size Operation

def size(self):
    return len(self.items)

10. Menu-Driven Stack Program

def menu():
    stack = Stack()
    while True:
        print("\n--- STACK MENU ---")
        print("1. Push")
        print("2. Pop")
        print("3. Peek")
        print("4. Display")
        print("5. Size")
        print("6. Exit")
        choice = int(input("Enter choice: "))

        if choice == 1:
            item = input("Enter item to push: ")
            stack.push(item)
        elif choice == 2:
            stack.pop()
        elif choice == 3:
            print("Top element:", stack.peek())
        elif choice == 4:
            stack.display()
        elif choice == 5:
            print("Stack size:", stack.size())
        elif choice == 6:
            print("Exiting...")
            break

12. Checking Balanced Parentheses

def is_balanced(expression):
    stack = []
    pairs = {"(": ")", "{": "}", "[": "]"}
    for char in expression:
        if char in pairs:
            stack.append(char)
        elif char in pairs.values():
            if not stack or pairs[stack.pop()] != char:
                return False
    return len(stack) == 0

print(is_balanced("({[]})"))   # True
print(is_balanced("({[})"))    # False

13. Infix to Postfix Conversion

def infix_to_postfix(expression):
    precedence = {"+": 1, "-": 1, "*": 2, "/": 2, "^": 3}
    stack = []
    result = []
    for char in expression:
        if char.isalnum():
            result.append(char)
        elif char == "(":
            stack.append(char)
        elif char == ")":
            while stack and stack[-1] != "(":
                result.append(stack.pop())
            stack.pop()  # Remove (
        else:
            while stack and stack[-1] != "(" and precedence.get(char, 0) <= precedence.get(stack[-1], 0):
                result.append(stack.pop())
            stack.append(char)
    while stack:
        result.append(stack.pop())
    return "".join(result)

print(infix_to_postfix("A+B*C"))  # ABC*+

14. Postfix Expression Evaluation

def evaluate_postfix(expression):
    stack = []
    for char in expression:
        if char.isdigit():
            stack.append(int(char))
        else:
            b = stack.pop()
            a = stack.pop()
            if char == "+": stack.append(a + b)
            elif char == "-": stack.append(a - b)
            elif char == "*": stack.append(a * b)
            elif char == "/": stack.append(a / b)
    return stack[0]

print(evaluate_postfix("23*5+"))  # (2*3)+5 = 11

15. Stack Limitations

  • Limited access: only the top element is accessible.
  • Not suitable for searching or accessing middle elements.
  • Array-based implementation has a fixed size if using static arrays.
  • Recursive function calls can cause stack overflow for deep recursion.

Very Short Answer Questions

Last In, First Out.

2. Name the end from which elements are added and removed in a stack.
Top.

3. Which list method is used for the push operation in Python?
append().

4. What is returned when pop() is called on an empty stack?
None or an underflow error.

5. What does the peek operation do?
It returns the top element without removing it.

Short Answer Questions

1. Explain the LIFO principle with a real-life example.
LIFO principle means the last element inserted is the first one removed. A real-life example is a stack of plates: the last plate placed on top is removed first. Similarly, in a stack data structure, the most recently pushed element is the first one popped.

2. Write the algorithm for push and pop operations.
Push: (1) Check if stack is full (if using array). (2) Increment top pointer. (3) Add element at top position. Pop: (1) Check if stack is empty. (2) Retrieve element at top. (3) Decrement top pointer. (4) Return the retrieved element.

Long Answer Questions

1. Implement a stack class in Python with push, pop, peek, isEmpty, size, and display methods. Write a menu-driven program to test it.
Create a Stack class with an internal list. push() appends to the list. pop() checks for emptiness then uses list.pop(). peek() returns list[-1]. is_empty() checks len == 0. size() returns len. display() shows elements from top to bottom. The menu-driven program offers a user interface to call each method.

2. Explain how a stack can be used to check balanced parentheses with an example.
Traverse the expression from left to right. When an opening bracket is encountered, push it onto the stack. When a closing bracket is encountered, check if the top of the stack has the matching opening bracket. If yes, pop it; otherwise, the expression is not balanced. After traversal, if the stack is empty, the expression is balanced. Example: "({[]})" is balanced; "({[})" is not.
